# RoutePilot — Logistics & Fleet Tracking Landing Page

A trendy, responsive React + Tailwind CSS landing page with eight required sections:
Navbar, Hero, About, Features, How It Works, Testimonials, Pricing, and Footer.

## Run locally

1. Install Node.js (LTS).
2. Extract this ZIP and open the project folder in VS Code.
3. Open a terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Notes

- Built with React, Vite, Tailwind CSS, and lucide-react icons.
- Responsive desktop, tablet, and mobile navigation/layouts.
- Pricing billing toggle, plan selection feedback, and newsletter form feedback are interactive demos.
- Pricing, testimonials, contact details, and metrics are illustrative sample content; replace them with real business information before publishing.
- Google Fonts are loaded from the web; system sans-serif fallbacks are included.
